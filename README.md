# ☕ MYTOKI Coffee Sales Dashboard

### 📊 Turning Coffee Sales Data into Business Insights with Microsoft Power BI

🚀 **A Data Analytics & Business Intelligence Project**

The **MYTOKI Coffee Sales Dashboard** is an interactive business intelligence project developed using Microsoft Power BI to analyze coffee shop sales performance, product trends, revenue distribution, and customer purchasing patterns.

By transforming raw transactional data into meaningful visual insights, this project demonstrates how data analytics can help businesses understand performance, identify trends, and make informed decisions.

## 🎯 Project Objectives

The primary objectives of this project are to:

- 📊 Analyze overall coffee sales and revenue performance.
- ☕ Identify top-performing and low-performing coffee products.
- 🕒 Understand purchasing patterns across different times of the day.
- 📅 Explore sales trends across weekdays and months.
- 📈 Transform raw transactional data into meaningful visualizations.
- 💡 Demonstrate practical business intelligence and data storytelling skills.

## 📈 Key Performance Indicators (KPIs)

The following metrics summarize the supplied dataset.

| 📌 Metric | 📊 Result |
|---|---:|
| 🧾 Total Transactions | 3,547 |
| 💰 Total Recorded Sales | 112,245.58 |
| 🛒 Average Transaction Value | 31.65 |
| ☕ Unique Coffee Products | 8 |
| 📅 Days with Recorded Transactions | 381 |
| 🗓️ Data Coverage | March 2024 – March 2025 |

> **Note:** The dataset does not explicitly specify a currency. Therefore, sales figures are presented without a currency symbol. The average transaction value is calculated from the recorded sales and transaction count.

## 🔍 Key Business Insights

### ☕ 1. Product Performance

- 🏆 **Latte** generated the highest recorded revenue, at 26,875.30.
- 📊 **Americano with Milk** recorded the highest transaction count, with 809 transactions.
- 📉 **Espresso** recorded the lowest revenue among the eight products.

**Business takeaway:** Product-level analysis helps identify popular items and products that may require further performance evaluation.

### 🕒 2. Time-of-Day Analysis

| Time Period | Recorded Sales |
|---|---:|
| 🌅 Morning | 35,929.20 |
| ☀️ Afternoon | 38,130.04 |
| 🌙 Night | 38,186.34 |

- 🌙 Night recorded the highest sales among the three periods.
- ☀️ Afternoon sales were very close to night sales.
- 📊 Sales were relatively evenly distributed across the recorded periods.

**Business takeaway:** Time-based analysis can help businesses explore demand patterns and evaluate staffing or operating-hour decisions.

### 📅 3. Weekly and Monthly Trends

- 🏆 **Tuesday** recorded the highest transaction count among weekdays, with 572 transactions.
- 📈 **March 2024** recorded the highest monthly transaction count in the dataset, with 494 transactions.
- 🔎 Monthly comparisons should account for data coverage and completeness.

**Business takeaway:** Weekly and monthly patterns can help identify periods of higher purchasing activity and support further demand analysis.

### 💳 4. Transaction and Payment Data

- 🧾 The dataset contains 3,547 transaction records.
- 💳 All supplied records are classified as card transactions.
- 📊 The available payment data does not support a meaningful comparison between different payment methods.

**Business takeaway:** Additional transaction data covering multiple payment methods could support more detailed payment behavior analysis.

## 🚀 Getting Started

### 📋 Prerequisites

Before exploring this project, make sure you have:

- 💻 Microsoft Power BI Desktop installed.
- 📁 Access to the source CSV dataset.
- 🌐 A GitHub account, if you want to clone or download the repository.

### ⚙️ Installation & Usage

**Step 1: Clone the Repository**

```bash
git clone https://github.com/naina-deep/Mytoki-coffee-.git
```

**Step 2: Open the Project**

Navigate to the downloaded repository folder.

**Step 3: Launch the Dashboard**

Open `COFFEEEE.pbix` using Microsoft Power BI Desktop.

**Step 4: Verify the Data Source**

If Power BI requests the source file, update the data source path to the downloaded `MYTOKI coffee sales.csv` file.

**Step 5: Refresh and Explore**

Refresh the dataset if required, then explore the available dashboard visuals and interactive filters.
